# Uproc

All-in-one business automation platform. Modular applications automate documents, finance, sales, data and operations. Each module handles one concrete business function and is activated as needed.

Deployment options include multi-tenant cloud and dedicated single-tenant instances. The interface supports English, Spanish and Catalan.

🔗 Website: https://uproc.io
📄 Documentation: https://docs.uproc.io
🔍 Tools catalog: https://uproc.io/applications/data-validation/tools

## What the platform does

| Area | Capabilities |
|---|---|
| 📄 Documents | Multichannel ingest, OCR classification & routing, PDF/A conversion, merge, batch numbering, archiving, multi-recipient e-signature, document generation from templates, audio and forms |
| 💶 Finance | Supplier invoice OCR, ERP sync, sales invoicing, tax compliance, debt tracking, bank reconciliation, investment analysis |
| 📈 Sales | CRM lead pipeline, prospecting & discovery, intelligence enrichment, multichannel campaign automation, editorial engine for WordPress, market signals |
| 🗄️ Data | No-code data management tables, ETL sync, natural-language data chatbot, file transfers (SFTP, S3, Dropbox, Drive) and a catalog of 469 pay-per-use data tools |
| 🛠️ Operations | Omnichannel customer care, email assistant, order tracking, inventory planning, approval workflows, process visibility, form generator |
| ⚖️ Legal & HR | Case lifecycle management, contract lifecycle, candidate evaluation |

## For AI agents

🤖 Uproc ships a native MCP server (JSON-RPC) with business-action tools, semantic shortcuts (module.collection.action) and the data-process tool catalog. Works with Claude Code, OpenCode, Cursor, Codex and any MCP client.
📄 Read the integration guide: https://docs.uproc.io

## Get started

1. Create an account at https://uproc.io
2. Pick a surface to run Uproc. Use brew install or scoop install via the tap repos for local development.
3. Automate with the integrations by connecting your preferred stack.
