# Uproc

**Uproc** is an AI-powered data platform: validate, enrich, transform and act on business data with **400+ data tools** — company, person, finance, geographic, communication and more — exposed through a visual app, a CLI, an MCP server and native integrations.

🔗 **Tool catalog & pricing:** [uproc.io/applications/data-validation/tools](https://uproc.io/applications/data-validation/tools)
📚 **Docs:** [docs.uproc.io](https://docs.uproc.io)

## Integrations (public)

| Repo | Description |
|------|-------------|
| [uproc-n8n](https://github.com/uproc-io/uproc-n8n) | Official n8n community node — source of the node published at n8n.io/integrations/uproc |
| [uproc-make](https://github.com/uproc-io/uproc-make) | Make.com integration for Uproc |
| [uproc-zapier](https://github.com/uproc-io/uproc-zapier) | Zapier integration for Uproc |
| [uproc-cli](https://github.com/uproc-io/uproc-cli) | Go CLI — authenticate, query data and run business workflows from the terminal |

## Self-hosted AI services (public)

The data pipeline runs on standalone, self-hostable AI microservices:

- [uproc-ocr](https://github.com/uproc-io/uproc-ocr) — Document OCR with RapidOCR (ONNX runtime)
- [uproc-tts](https://github.com/uproc-io/uproc-tts) — Text-to-Speech with Piper TTS
- [uproc-n8n-fork](https://github.com/uproc-io/n8n-fork) — Fair-code workflow automation fork with native AI capabilities
