# Uproc
All-in-one business automation platform. Modular applications automate documents, finance, sales, data and operations. Each module handles one concrete business function and is activated as needed. The platform supports cloud and dedicated deployment modes. It runs in English, Spanish and Catalan.

[Website](https://uproc.io){:target="_blank" rel="noopener"} | [Documentation](https://docs.uproc.io){:target="_blank" rel="noopener"} | [Tools Catalog](https://uproc.io/applications/data-validation/tools){:target="_blank" rel="noopener"}

## What the platform does
The platform comprises 37 modules. Each module targets a specific business function.

| Area | Capabilities |
|---|---|
| Documents | Multichannel ingest, OCR classification & routing, PDF/A conversion, merge, batch numbering, archiving, multi-recipient e-signature, document generation from templates, audio and forms |
| Finance | Supplier invoice OCR, ERP sync, sales invoicing, tax compliance, debt tracking, bank reconciliation, investment analysis |
| Sales | CRM lead pipeline, prospecting & discovery, intelligence enrichment, multichannel campaign automation, editorial engine for WordPress, market signals |
| Data | No-code data management tables, 469 data-process tools, ETL sync, natural-language data chatbot, file transfers via SFTP, S3, Dropbox and Drive |
| Operations | Omnichannel customer care, email assistant, order tracking & ingest, inventory planning, approval workflows, process visibility, form generator |
| Legal & HR | Case lifecycle, contract lifecycle, candidate evaluation |

## For AI agents
Uproc ships a native MCP server (JSON-RPC) with business-action tools, semantic shortcuts (module.collection.action) and the data-process tool catalog. Works with Claude Code, OpenCode, Cursor, Codex and any MCP client.

[Read the MCP documentation](https://docs.uproc.io){:target="_blank" rel="noopener"}

## Get started
1. Create an account at [uproc.io](https://uproc.io){:target="_blank" rel="noopener"}.
2. Pick a surface to work on. Install the CLI via brew or scoop, or use the terminal directly.
3. Automate with the integrations listed above.

Contact support@uproc.io for setup assistance.
