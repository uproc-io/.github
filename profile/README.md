# Uproc

All-in-one business automation platform. Modular applications automate documents, finance, sales, data and operations. Each module handles one concrete business function and is activated as needed.

The platform runs on cloud or dedicated single-tenant instances. Supports English, Spanish and Catalan.

[Website](https://uproc.io) | [Documentation](https://docs.uproc.io) | [Tools Catalog](https://uproc.io/applications/data-validation/tools)

## What the platform does

| Area | Capabilities |
|---|---|
| Documents | Multichannel ingest, OCR classification & routing, PDF/A conversion, merge, batch numbering, archiving, multi-recipient e-signature, document generation from templates/audio/forms |
| Finance | Supplier invoice OCR + ERP sync, sales invoicing, tax compliance, debt tracking, bank reconciliation, investment analysis |
| Sales | CRM lead pipeline, prospecting & discovery, intelligence enrichment, multichannel campaign automation, editorial engine, market signals |
| Data | No-code data management tables, ETL sync, natural-language data chatbot, file transfers, 469 data-process tools |
| Operations | Omnichannel customer care, email assistant, order tracking, inventory planning, approval workflows, process visibility, form generator |
| Legal & HR | Case lifecycle, contract lifecycle, candidate evaluation |

## For AI agents

Uproc ships a native MCP server (JSON-RPC) with business-action tools, semantic shortcuts (module.collection.action) and the data-process tool catalog. Works with Claude Code, OpenCode, Cursor, Codex and any MCP client. See the documentation for setup guides.

## Get started

1. Create an account at [uproc.io](https://uproc.io).
2. Pick a surface to access the platform. Install the CLI via Homebrew or Scoop tap repos, or use the web dashboard.
3. Connect your stack using the n8n, Zapier or Make integrations to automate workflows.
Contact support@uproc.io for assistance.
