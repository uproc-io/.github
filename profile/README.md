# Uproc

All-in-one business automation platform. Modular applications automate documents, finance, sales, data and operations. Each module handles one concrete business function and is activated as needed. The platform runs on cloud or dedicated single-tenant instances.

🔗 Website: https://uproc.io
📄 Documentation: https://docs.uproc.io
🔍 Tools catalog: https://uproc.io/applications/data-validation/tools

## What the platform does

The platform covers six core business areas. It ships 37 modules and a catalog of 469 data tools.

| Area | Capabilities |
|---|---|
| 📄 Documents | Multichannel ingest, OCR classification & routing, PDF/A conversion, merge, batch numbering, archiving, multi-recipient e-signature, document generation from templates/audio/forms |
| 💶 Finance | Supplier invoice OCR, ERP sync, sales invoicing, tax compliance, debt tracking, bank reconciliation, investment analysis |
| 📈 Sales | CRM lead pipeline, lead prospecting & discovery, lead intelligence enrichment, multichannel campaign automation, editorial engine, market signals |
| 🗄️ Data | No-code data management tables, data-process tool catalog, ETL data sync, natural-language data chatbot, file transfers (SFTP/S3/Dropbox/Drive) |
| 🛠️ Operations | Omnichannel customer care, email assistant, order tracking & ingest, inventory planning, approval workflows, process visibility, form generator |
| ⚖️ Legal & HR | Case lifecycle, contract lifecycle, candidate evaluation |

## For AI agents

🤖 Uproc ships a native MCP server (JSON-RPC) with business-action tools, semantic shortcuts (module.collection.action) and the data-process tool catalog. Works with Claude Code, OpenCode, Cursor, Codex and any MCP client.

📄 Read the integration guide: https://docs.uproc.io
